# HOST BUILD AND TEST packages above unless another dependency is stated.

NOT MANAGED BY THIS APT MANIFEST
# Reviewed ARM64/x86-64 Vosk libraries and a shared model are under root-level xWalkLibrary.

# Ollama requires its executable and separately downloaded model manifests.
# setup-rpi.sh can install explicitly supplied repository-controlled Vosk assets.
# setup-rpi-local.sh owns the user-local Ollama installation; setup-rpi.sh only validates
# that result when --validate-ollama is selected.
